## First Look at VisualGDB

VisualGDB is for people who keep firmware they own and want one named Visual Studio desk, not mixed board copies. It gives you an embedded desk, own firmware, and a short path back to a board you already run. It does not replace Visual Studio. It sits beside Visual Studio and keeps the project close.
